
1. Định nghĩa
	- Khi x -> x0, limf(x) = 0 thì f(x) được gọi là VCB
				VD: lim(sin(x)) = 0 khi x -> 0
					lim(x) = 0 khi x -> 0
					lim(1/x) =0 khi x -> +-oo
	
	- Khi x -> x0, lim|f(x)| = oo thì f(x) được gọi là VCL
			- limf(x) = oo
			- limf(x) = -oo
				VD: ln(x) -> -oo khi x -> 0+
					tanx -> +oo khi x -> pi/2
					tanx -> -oo khi x -> -pi/2
					e^x -> +oo khi x -> +oo
