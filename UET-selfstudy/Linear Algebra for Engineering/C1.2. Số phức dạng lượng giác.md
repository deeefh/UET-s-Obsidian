
1. Số phức
	a) Định nghĩa
			z = a + bi
				(a, b: real; i: imaginary; i^2 = -1)

	- Liên hợp của z:
			z- = a - bi

			z*(z-) = a^2 + b^2   -> Số thực

	- Module z
			|z| = sqrt(z*(z-)) = sqrt(a^2 + b^2)    -> Khoảng cách từ O đến M(a;b)

			a = Re(z)
			b = Im(z)

	b) Biểu diễn z
		- Giống Oxy, a ~ x 
				 b ~ y

		- z-(a;-b) là đối xứng của z(a;b) qua Ox

	c) Phép toán
			`(a + bi) + (c + di) = (a + c) + (bi + di) = (a+c) + (b + d)i`
		`
			`(a + bi)(c + di) = (ac - bd) + (ad + bc)i`
				(thực thực, ảo ảo)

			(a + bi)/(c + di) = ((a + bi) * (c - di))/(c + di)^2
				(Nhân liên hợp)

2. Dạng lượng giác 
	a) Biểu diễn z
	- Cho M là điểm bao đầu của z trên Oxy, phi = (vec(Ox), vec(OM)) = argument(z)
			(+: Ngược kim đồng hồ)
			(-: Cùng kim đồng hồ)

	b) Định nghĩa z ở tọa độ cực
		`z = r(cos(phi) + i*sin(phi))`

		z- = r(cos(-phi) + i*sin(-phi))
				(r = module(z) = |z|)
				
				(Luôn là dấu '+', nếu viết thành dấu '-' là sai)
					-> Tìm cách nhét dấu '-' vào trong sin, nếu thấy trước sin là dấu '-'

			(Dùng vòng tròn lượng giác, đơn giản là tìm cạnh)

	c) Phép toán
		`[r1(cos(phi1) + i*sin(phi1)][r2(cos(phi2) + i*sin(phi2))]
				`= r1*r2*[cos(phi1 + phi2) + i*sin(phi1 + phi2)]`
